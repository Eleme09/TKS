Al crear un equipo se muestra un token una sola vez. Se pega en el archivo de configuración del agente. Si se pierde, se borra el equipo y se crea otro.

Windows no permite inyectar esta combinación por software (es la "secuencia de atención segura"). Si hace falta bloquear la sesión o abrir el administrador de tareas, usa Ctrl+Shift+Esc.
