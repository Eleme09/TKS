Cómo funciona / limitaciones

Chaturbate no expone historial retroactivo de tokens vía API — solo eventos en vivo. Este backend corre server-to-server (por eso no hay bloqueo CORS, a diferencia de llamarlo directo desde el navegador) y guarda cada tip recibido en data/<username>.json, con fecha real.

  • El total de la quincena actual se calcula sobre lo que este servidor ha capturado desde que empezó a correr — no trae datos de antes de eso.
  • Periodos: día 1-15 se paga el 20 del mismo mes; día 16-fin de mes se paga el 5 del mes siguiente.
  • Mientras el proceso node server.js siga corriendo (aunque cierres esta pestaña), sigue capturando.
  • Si lo cierras y lo vuelves a abrir, el historial ya guardado en data/ se conserva.
  • El token solo vive en memoria del servidor mientras está conectado; no se guarda en disco.
