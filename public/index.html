Escuchando la Events API oficial en tiempo real, por modelo, con reporte de quincena.
Todavía no has agregado ninguna modelo.
Cómo funciona / limitaciones

Chaturbate no expone historial retroactivo de tokens vía API — solo eventos en vivo. Este servidor guarda cada tip recibido por modelo, con fecha real, y calcula el total de la quincena en curso.

  • El total de cada quincena se calcula sobre lo que este servidor ha capturado desde que empezó a rastrear a esa modelo — no trae datos de antes.
  • Periodos: día 1-15 se paga el 20 del mismo mes; día 16-fin de mes se paga el 5 del mes siguiente.
  • En línea / desconectada: se detecta con los eventos oficiales de inicio/fin de transmisión. Si la modelo ya estaba transmitiendo antes de agregarla aquí, el estado aparece como "Desconocido" hasta el primer evento real (el próximo inicio o fin de transmisión).
  • El token de cada modelo solo vive en memoria del servidor mientras está conectado; no se guarda en disco.
  • Cotización del dólar (USD → COP) de una fuente pública gratuita. Esa fuente se actualiza aprox. una vez al día (no segundo a segundo — eso solo lo dan feeds de mercado de pago), por eso siempre se muestra la hora exacta de la última actualización junto al precio.
